## 📄 HOW TO CONVERT PPT TO PDF WITHOUT BREAKING CLICKABLE BUTTONS

When submitting your presentation deck to the **Smart India Hackathon (SIH 2026) Portal in PDF format**, follow these rules so all button links stay **100% active and clickable** for evaluating judges:

1. **In Microsoft PowerPoint (Windows / Mac):**
   * 🛑 **DO NOT use "Print to PDF"** (The printer driver flattens text into static images and strips all hyperlinks!).
   * ✅ **DO use "Export / Save As PDF"**:
     * Go to **File ➔ Save As** (or **Export**).
     * Select **File Type: PDF (*.pdf)**.
     * Ensure **"Standard (publishing online and printing)"** is selected.
     * Click **Save / Export**. This embeds native hyperlinked PDF annotations!

2. **In Canva:**
   * Click **Share ➔ Download**.
   * Choose **File Type: PDF Standard** (or PDF Print).
   * 🛑 **UNCHECK "Flatten PDF"** (Flattening destroys clickable links!).

3. **In Gamma.app:**
   * Click **Share ➔ Export ➔ Export to PDF**.
   * Gamma generates a high-res PDF with all button links intact.

4. **In Google Slides:**
   * Go to **File ➔ Download ➔ PDF Document (.pdf)**.

5. **Final Verification Step before SIH Upload:**
   * Open the generated PDF in **Google Chrome, Microsoft Edge, or Adobe Acrobat Reader**.
   * Hover your cursor over the button shapes on Slide 6.
   * Verify that the mouse cursor changes into a **pointing hand icon 👆** and shows the full URL in the bottom-left preview bar!
